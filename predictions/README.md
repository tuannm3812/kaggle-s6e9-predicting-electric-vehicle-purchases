# Prediction matrices (gitignored)

One pair of aligned NumPy vectors per run, named by the run's ledger
primary key:

    {run}_oof.npy    668,665 out-of-fold predictions, train-row order
    {run}_test.npy   286,571 test predictions, test-row order

Alignment is what makes them useful: every run shares fold definition F1
(5-fold) or F2 (10-fold) from `docs/4_experiment_ledger.md`, so any two
same-class OOF vectors are directly comparable row-for-row — the paired
promotion gate, the free screens and the stacking screen all consumed
these files. Provenance: fetched from the Kaggle kernel run that the
run's ledger row cites (`kaggle kernels output`); local files are copies
of kernel artifacts, never locally-executed substitutes. CPU runs have
reproduced these vectors bit-identically across kernel versions seven
times, so a missing file can be regenerated by re-running its flag.
